# 00. プロダクト概要

## ひとことで

**家族・友人グループ向けの招待制 飲食店レビュー SPA**。完全無料運用（GitHub Pages + Supabase Free Tier）。

## 対象ユーザー

- 家族・友人など 10 人未満の信頼ベース小グループ
- スマホ中心利用（PC からも見られる）

## 提供する価値

- 共有の店舗マスタにグループのみんなが評価を貯めていける
- 5 軸 × 1〜10 段階のシンプルな評価軸で「何が良かったか」を粒度高く残せる
- Google Maps / 食べログへワンタップで飛べるので、外部の客観評価は本家で見られる
- 写真を要求しないので登録のハードルが低い

## コア機能

| 機能 | 内容 |
|---|---|
| 招待制サインアップ | Google SSO + 合言葉。合言葉照合は OAuth の後で Edge Function が行う |
| 店舗登録 | 店名・ジャンル・価格帯・Google Maps URL・食べログ URL・その他リンク。訪問・評価なしでも可 |
| 訪問・評価 | 訪問日 / 注文 / 支払金額 / コメント（任意） + 5 軸 10 段階評価（任意） |
| 一覧 | 店名・ジャンル・価格帯・総合評価でフィルタ。新着 / 評価高い / 名前順 |
| 詳細 | 平均評価・地図ピン・外部リンク・他メンバーの訪問記録一覧 |
| ユーザー履歴 | 各メンバーが訪問した店舗一覧 |
| メンバー一覧 | 自分のプロフィールから他メンバーへ飛べる |

## 評価軸

| キー | ラベル |
|---|---|
| `overall` | 総合 |
| `food` | 料理 |
| `service` | サービス |
| `atmosphere` | 雰囲気 |
| `cost_performance` | コスパ |

すべて整数 1〜10 で必須（評価を入れる場合）。`src/lib/constants.ts` の `RATING_AXES` で定義。

## 価格帯

`〜2000 / 2000〜5000 / 5000〜10000 / 10000〜20000 / 20000〜`（円）の 5 段階 enum。
Postgres 側は `price_range_enum`、TS 側は `PRICE_RANGES`（`src/lib/constants.ts`）で同期。

## 運用前提

- Free Tier 上限：DB 500MB / 帯域 5GB/月 / Edge Function 500K invocations/月
- Supabase Free Tier は **1 週間 API 無アクセスで自動 Pause** → 毎日 03:00 JST に GitHub Actions が REST を叩いて防止
- 写真機能を持たないため帯域・容量はかなり余裕がある想定

詳細は [`11-non-goals.md`](./11-non-goals.md) も参照。
